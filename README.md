# Jagmohan Singh — Portfolio V2

A LinkedIn-style personal portfolio website for **Jagmohan Singh** — Web Designer & Front-End Developer.

Built with **React + Vite + Tailwind CSS**.

---

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React 19, Vite (rolldown-vite), Tailwind CSS 3 |
| Icons | react-icons |
| Deployment | GitHub Pages (current) → Vercel (planned) |
| Backend (planned) | Node.js, Express |
| Database (planned) | PostgreSQL + Prisma ORM |
| Email (planned) | Resend API |
| Auth (planned) | HTTP-only cookies, bcrypt |

---

## Design Direction

- LinkedIn-style card layout
- Clean white background, slate tones
- Inter font (body + headings)
- No glassmorphism, no dark themes, no decorative fonts
- Responsive: mobile → tablet → desktop
